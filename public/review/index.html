매장 검색부터 정확하게,
실제 후기 기반으로.

상호명이 정확히 일치하지 않아도 비슷한 이름·전화번호·주소를 함께 비교해 실제 매장 후보를 찾습니다. 주소는 카카오맵·네이버 결과를 우선하고, 다이닝코드는 지도 결과가 없을 때 보조로 사용합니다.
🧾 영수증 자동 입력사진 저장 안 함
영수증은 상호명·전화·주소를 함께 읽고, 읽힌 정보로 실제 매장을 다시 검색합니다. 확실하지 않은 글자는 억지로 확정하지 않습니다.
상호명 또는 장소명 영수증이면 자동
주소는 카카오맵 → 네이버 → 다이닝코드 순으로 우선합니다. 검색 결과에 ‘주소 기준: 카카오맵/네이버’가 표시되면 그 지도 주소를 사용합니다.
먹은 메뉴 선택 · 영수증이면 자동
선택한 매장의 공개 메뉴정보와 맞지 않는 메뉴는 리뷰 생성 전에 다시 확인합니다. 공개 메뉴를 충분히 확인하지 못한 경우에도 그대로 통과시키지 않고 확인창을 띄웁니다.

요청 문장을 그대로 복사하지 않고 작성 지시로 해석합니다.
